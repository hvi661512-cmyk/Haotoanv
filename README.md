🎮 HÀO TOÁN RPG

Hào Toán RPG là game giải toán kết hợp nhập vai RPG, nơi người chơi vừa rèn luyện khả năng tính toán vừa tích lũy điểm số, XP và tiền xu để mở khóa các phần thưởng.

✨ Tính năng

* 🟢 Chế độ dễ (Easy).
* 🟡 Chế độ trung bình (Medium).
* 🔴 Chế độ khó (Hard).
* ♾️ Chế độ sinh tồn (Survival).
* 🏆 Lưu kỷ lục riêng cho từng chế độ.
* ⭐ Hệ thống XP và cấp độ.
* 🪙 Hệ thống tiền xu.
* 🎯 Nhiệm vụ hằng ngày.
* 🏅 Thành tựu.
* 🎨 Cửa hàng giao diện.
* 🔊 Âm thanh trả lời đúng và sai.
* ⚙️ Khu vực ADMIN với thử thách mở khóa.

🛠️ Công nghệ

* HTML5
* CSS3
* JavaScript
* LocalStorage

🚀 Cách chơi

1. Mở game.
2. Chọn chế độ chơi.
3. Giải các phép toán xuất hiện trên màn hình.
4. Tích lũy điểm, XP và tiền xu.
5. Phá kỷ lục và mở khóa thành tựu.

📂 Cài đặt trên GitHub

1. Tạo một repository mới.
2. Tải file index.html lên.
3. Vào Settings → Pages.
4. Chọn nhánh main.
5. Nhấn Save để xuất bản game.

💾 Lưu dữ liệu

Game sử dụng LocalStorage để lưu tiến trình trên trình duyệt.

Lưu ý: Dữ liệu được lưu trên thiết bị và trình duyệt đang sử dụng.
